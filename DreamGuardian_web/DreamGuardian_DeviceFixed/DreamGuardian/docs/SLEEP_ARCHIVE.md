# 历史睡眠归档

前端通过 IndexedDB 保存当前浏览器采集到的会话，每 5 秒合并一次样本和事件；明确收到睡眠计时器结束标志后归档。按会话 ID 去重，刷新后继续合并未结束记录。正式数据和离线模拟使用不同数据库。仅完成记录进入历史列表。

这是浏览器本地保存，不是服务器归档：浏览器关闭期间无法采集，清除网站数据会删除本地记录，更换设备、浏览器或网站域名不能共享。生产后端应持续采集并持久化完整会话。

历史报告的选择器和“查看历史记录”按钮可打开任意会话；有有效评分的最近七次会话也可从柱状图点击进入。页面复用睡眠时间轴布局、缩放和事件详情，以独立历史状态显示，返回按钮回到历史报告。

后端 `/api/sleep/reports/{session_id}` 可提供 `history`（或 `samples`）时间序列、`events` 事件快照、`timer`（started_unix、ended_unix、running:false、session_id），以及原有的 score、assessment、issues、suggestions。

无历史序列时显示空时间轴，不以当前实时序列替代。无评分的本地会话仍可由列表打开。已有接口报告与本地记录按会话 ID 合并。离线七次示例的曲线、事件、分数均为演示数据。
