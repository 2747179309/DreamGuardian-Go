# 小梦动态陪伴版

进入「AI 小梦」查看角色舞台、陪伴偏好、实时情境提示与对话卡片。展开角色下方的「互动演示」，可播放完整流程或单独体验状态。演示只更新画面和文案，不录音、不播放声音、不请求设备操作。

## 本版行为

- 沿用五套透明角色素材，补充呼吸、摆动、指针倾斜、450ms 叠化、状态光环与星点。十一种状态包括待机、唤醒、倾听、思考、回答、守护、变化、确认、执行、完成、错误。
- 支持三种陪伴偏好和动效开关，保存在此浏览器；关闭动效或系统减少动态效果时停止角色动画。
- 情境提示来自当前有效数据。离床、状态变化、睡眠守护和数据缺失分别显示不同提示。主动消息有冷却时间，安静偏好不主动插入消息。
- 对话支持本地睡前陪伴、睡眠报告入口、灯光降低15个百分点、音量降低5个百分点、暂停声音。设备操作通过确认卡片调用既有 sendControl，收到成功回执后才显示完成。
- 自由数据问题继续走 /api/ai/query，保持 question/scope/require_sources 协议。离线规则回复有明确标记。消息显示可展开依据和本次页面反馈，不将反馈上传或宣称训练模型。
- 最多保留60条当前页面消息；偏好持久化，对话不持久化。Enter发送，Shift+Enter换行，兼容中文输入法组合输入。

## 接入与限制

`xiaomeng-companion.js` 在 app.js 后加载，复用全局状态、数据有效性判定与控制入口。sendControl 新增结果返回值，原有控制调用方式继续可用。实时语音状态不会覆盖尚未结束的用户交互，恢复时重新读取实时状态。

本版使用现有位图姿态与前端动效，尚未制作独立眼部/嘴部骨骼，因此没有真实眨眼、逐音素口型或真实音量驱动。网页不新增麦克风权限；倾听来自 NX 语音状态或明确的演示。未新增定时控制、机械臂动作或自动设备干预。

生产页为 static/index.html；使用 tools/sync-offline.ps1 同步 static/offline.html。原有 Windows 启动入口保持可用。无需新依赖或构建步骤。
