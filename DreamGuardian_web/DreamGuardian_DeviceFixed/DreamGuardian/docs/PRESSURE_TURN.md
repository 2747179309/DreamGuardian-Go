# 枕压驱动人物翻身

卧室数字孪生使用当前六点枕压驱动人物连续侧转，点击「人体」聚焦，侧栏显示模拟方向、角度、压力重心及暂停/继续按钮。离线页使用原有合成压力变化，生产页使用实时遥测；不发送任何设备控制命令。

## 输入与方向

优先使用 pillow.pressure_zones，其次 sample.pressure_matrix，均为上排 P1/P2/P3、下排 P4/P5/P6，范围0–100。左列为P1+P4，右列为P3+P6，平衡值为（右列−左列）/六点总和。

左右指枕头测点布局，非用户解剖学左右。当前 bedroom.glb 床长轴为场景Z轴、左右为X轴。实际安装需核对测点方向，反向安装应调整映射，不能将这个模拟输出当成实际体位识别结果。

## 平滑与保护

平衡值使用0.35秒指数滤波；超过±0.18进入侧转，回到±0.08以内恢复仰卧。候选状态需持续至少650ms。最大侧转55度，临界阻尼使姿态在约2秒内平滑收敛，反向变化从当前角度继续。

六点不全、数值无效、总压力低于12、设备离线、离床或时间戳超过4.5秒时，保持当前姿态，不继续推演。时间戳优先pillow.received_at，其次sample.unix_time或sample.timestamp。无新样本时动画循环也检查超时。暂停动画不会停止数据接收；恢复后向最新姿态平滑过渡。系统减少动态效果时直接显示目标姿态。

## 模型实现

原始GLB没有骨骼或动画片段。运行时克隆人物几何，保留原有材质和细节，以沿床长方向连续变化的旋转权重表现躯干与下半身跟随；所有面部和服装细节应用同一空间变换。每帧从原始顶点计算，避免累计变形。人物最低点保持在原始支撑平面。属于程序化姿态示意，不是具有完整关节、床垫接触和布料物理的动画。

源文件 static/pressure-turn.mjs；scene3d.js接入。修改后运行 node tools/build-3d.cjs，并同步离线HTML。验证脚本 node tools/test-pressure-turn.mjs 覆盖左右/仰卧、反向连续性、小幅噪声、缺失/断流/离床/无接触、暂停、细节附着与支撑平面。
