# 睡眠时间轴

- 三个主要高度为清醒、浅睡、深睡；沿用 sleep_state 的现有映射，不推导 REM 或第三种睡眠深度。其他状态保留原始含义，点击色块查看。
- 宽度按采样时间计算；相邻同状态合并。超过典型采样间隔三倍的空档显示为未知，避免按样本数量分配时长。
- 标记使用已有 turn、intervention、snore、leave_bed、return_bed 事件及历史样本的对应变化。翻身次数增加也生成标记；none / idle 不作为干预。
- 图中展示所选记录范围内全部受支持的事件，不受旧版四条关键事件列表上限影响。重复的同类同时间事件去重。
- 按钮或滑块缩放 1–64 倍；鼠标滚轮以指针位置缩放，拖动平移，触屏双指缩放。键盘 +/- 缩放、左右键平移、0 重置。
- 密集标记显示事件数量，点击打开可逐条选择的列表并联动事件溯源；色块可点击查看阶段及起止时间。
- 生产页面和离线页面共用实现，离线页通过 tools/sync-offline.ps1 生成。
