# DreamGuardian 网页组修改说明 V7

日期：2026-09-13

- 删除首页“ESP 脑电 Alpha”指标卡，改为可点击进入详情页的原始 EEG 时域波形。
- 将心率、呼吸、体动三张实时趋势图合为一张共享时间轴、独立量程的三泳道图。

- 删除左侧导航中的“ESP扩展数据”独立入口。

- 将首页“ESP 脑电 Alpha”数据卡升级为可触摸入口，点击整张卡片即可进入原 ESP 扩展传感器页面。
- ESP 详情页增加“返回实时检测”按钮，便于触摸屏返回首页。
- 保留原有 ESP 数据绑定、实时波形、频带功率和扩展指标功能，不修改接口字段。
- 同步修改生产页、Windows 离线演示页与根目录页面。
- 更新 CSS 与 app.js 缓存版本，避免浏览器继续使用旧文件。

- 无接口字段变化。
- 仍从现有实时数据中的 `esp` 对象读取数据。
