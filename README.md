# DreamGuardian-Go
DreamGuardian mvp的升级版！添加了Jetson orin nx的算力模块并训练睡眠状态检测模型和梦魇模型，加入so-arm101机械臂并利用自己的VLA模型帮助用户拿取床上用品！The upgraded version of DreamGuardian MVP! It adds a Jetson Orin NX computing module and trains sleep state detection and nightmare models, includes the so-arm101 robotic arm, and uses its own VLA model to help users grab items from the bed!
